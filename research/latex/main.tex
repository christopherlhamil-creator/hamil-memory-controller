\begin{abstract}
This preprint presents the Hamil Memory Controller, a fixed-geometry cellular
substrate and semantic sidecar that separates cache-local hot state from an
asynchronous SQLite persistence projection. The manuscript is authored by
Christopher Hamil and reports the measured locality and sidecar results in the
versioned proof artifacts accompanying the source tree.
\end{abstract}

\section{Contribution and Geometry}
Christopher Hamil's substrate fixes each cell at 17,408 bytes, or 272 cache
lines. Its first cache line is the 64-byte instruction header
\texttt{=Q16s16s16sII}, co-locating the opcode, subject, predicate, object,
flags, and epoch \cite{hamil2026cellular}.

\section{Spoke Manifolds and the Semantic Sidecar}
The Spoke Manifold Principle selects a domain-local header working set before
traversal. Ten thousand 64-byte headers occupy 640,000 bytes (625 KiB), while
the complete cell payload remains governed by the fixed geometry. The local
proof artifacts report the resulting warm-spoke throughput and LLC behavior
\cite{hamil2026query,hamil2026spoke}.

The Semantic Sidecar admits transactions into aligned cells without SQL work
on the hot path. A background worker drains committed cells into SQLite,
preserving a conventional relational projection for cold queries
\cite{hamil2026sidecar,hamil2026sidecarcode}.
